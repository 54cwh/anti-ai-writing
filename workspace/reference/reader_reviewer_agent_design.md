# 读者代理 × 审稿人代理：设计构想（v0.1 草稿）

**记录日期**：2026-10-27
**状态**：基础想法已定，实现方案待专门研究。本文只记结论，不记推导过程（推导见 `fake_logic_taxonomy.md` 与 `practitioner_insights_platforms.md`）。

---

## 一句话

两个子代理分工测两个德性：

- **读者代理**测「可教学性」——一个只有基础知识的个体，能不能靠读这篇文章学到东西。
- **审稿人代理**测「可辩护性」——因果主张的识别模型站不站得住。

**假逻辑 = 可教学性高 + 可辩护性低。** 学得会，但学的是错的。这一格就是全部目标。

---

## 为什么必须是两个

同一个病灶，两条独立通路：

- 读者：对「缺」会懵，对「假」会**顺畅地自己补上、且没意识到**。后者是假逻辑存活的证据。
- 审稿人：把补的那句拆开，看它成不成立。

缺任何一半都不行。只有读者，你知道补了什么、不知道补得对不对；只有审稿人，你知道某处不成立、不知道读者会不会被这一处骗过去。

**产出不是谁抓到，是两条通路的一致性。**

---

## 读者代理

**锚定**：只有基础知识的个体，通过阅读本文来学习该领域。

**输出**：学习者口气的提问，每条对应一个可查缺陷：

| 学习者会问 | 暴露的缺陷 |
|---|---|
| 这是什么意思？ | 术语未定义 |
| 这个概念之前出现过吗？ | 指称断裂 |
| 这里是不是少了一段？ | 论证缺口 |
| 为什么从 A 直接跳到 B？ | 因果虚接 |
| 所以结论到底是什么？ | 主张不清 |
| 这跟我刚读的那段矛盾吗？ | 内部不一致 |
| 这个数从哪来的？ | 依据缺失 |

**核心测量：不自觉补全。**

> 读者补了什么，以及它知不知道自己在补。
> 补了且自觉 → 缺口暴露；补了且不自觉 → 假逻辑骗过了读者；没补 → 结实或断裂。

**方法坑**：不能一开始就提示「注意你补了什么」，否则就不自然了。必须**先重建，后追问**——第一遍只让它复述论证，第二遍再问「你刚才写的东西里，哪些原文没有」。

**边界**：本文自造的概念必须定义；领域公共知识可以假定。不定这条，误报率会很高。

---

## 审稿人代理

**只查识别，不查表达。** 不看句子顺不顺，看因果主张是怎么被识别出来的。

**检查链**：

1. 主张类型（相关 / 条件因果 / 机制 / 反事实）
2. 声称强度
3. 识别策略：文中明说还是隐含
4. 该领域标准策略（需外部知识）
5. 必要假设，检验了吗
6. 主要威胁（混淆、选择、测量、反向、外推），逐个排除还是跳过
7. 强度匹配：识别强度撑得起结论吗
8. 替代方案：有没有更强的识别模型

**最终产物 = 替代识别策略，不是评价。**

> 不要让它说「这篇有问题」，让它说「应该换成这个识别策略，理由是……」。

理由：生成是强项、判断是弱项；替代方案可检验、评价不可检验；天然堵住「整体而言，建议进一步完善」。

**防糊弄四约束**（对应「不要假装就糊弄过去」）：

1. 每个判断必须挂句号。
2. 必须分开「文中说了」和「我认为」。
3. 「没问题」要交付作业：查了哪几项、看的哪句、什么证据会推翻判断。
4. 禁止总体评价、优点、建议。

**瓶颈**：不是提示词，是领域知识。没有该领域的识别策略清单，它只能说「可能存在混淆变量」——那是「优点三条缺点两条」的等价物。

## 交叉表

| 读者（可教学性） | 审稿人（可辩护性） | 诊断 |
|---|---|---|
| 通 | 通 | 结实 |
| 通 | **不通** | **假逻辑**（学得会，学的是错的） |
| 不通 | 通 | 表达问题（结论对，没讲清楚，常被误判为 AI 味） |
| 不通 | 不通 | 硬伤，或根本没论证 |

## 待专门研究：读者怎么实现

1. 「不自觉补全」怎么量化？先粗分（0 补 / 补 1 句 / 补 ≥2 句），要不要更细。
2. 「先重建后追问」和「一开始就标注」，哪个更保真？需要实测。
3. 同源盲区：读者是否必须换模型 / 用弱模型 / 去体裁化输入？提示词解决不了。
4. 读者锚定谁：跨学科读者 / 同领域研究生 / 竞赛评委？不同锚定，输出完全不同。
5. 「懵」的真伪判定：缺先修知识 vs 文本缺失，怎么机械化区分。

## 待专门研究：审稿人怎么实现

1. 领域识别策略清单从哪来（经济学 IV/DID/RDD、流行病学队列/孟德尔随机化、社会学过程追踪……）。
2. 通用 vs 领域专用：通用模型怎么知道某领域的标准设计。
3. 代理输出「替代策略」是否真的更强——这需要领域专家人工判，本身是道验证题。

## 证据基础

- 假逻辑框架、缺/假二分、读者自责效应：`fake_logic_taxonomy.md`
- 因果虚接、无代价、实践者经验：`practitioner_insights_platforms.md`
- 定位外部化（AI 找不到错误、但给位置能改）：Tyen et al., ACL 2024；Huang et al., ICLR 2024
- 独立作答降低幻觉（CoVe 原则）：Dhuliawala et al. 2023
