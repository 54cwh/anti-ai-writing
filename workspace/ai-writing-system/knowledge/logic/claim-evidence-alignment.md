# Claim-Evidence Alignment
## 判断与证据的对应关系

## 1. 文件目的

本文件研究判断、证据及其支持关系，重点解决模型在写作中出现的证据使用不当、结论过度延伸和判断强度失衡等问题。

一项判断能否成立，取决于其所依赖的事实、资料和推理过程。

例如：

「某项政策促进了企业创新。」

这项判断可能需要以下内容支持：

- 政策确实已经实施。
- 企业实际受到政策影响。
- 企业创新产出发生了变化。
- 这种变化能够合理归因于政策。
- 研究设计能够排除重要的替代解释。

其中，每一项内容都涉及不同的证据要求。

如果模型只掌握政策实施后的企业专利数据，就需要进一步分析这些数据能够支持什么判断。

本文件重点研究：

1. 判断与证据的基本概念。
2. 不同类型判断的证据要求。
3. 证据的不同形式。
4. 证据的相关性与充分性。
5. 证据的可靠性与有效性。
6. 判断强度的确定。
7. 证据与推理之间的关系。
8. 多项证据的组织。
9. 相互冲突的证据处理。
10. 证据缺口的识别。
11. 判断与证据的动态调整。
12. 写作前的证据准备。
13. 写作过程中的证据检查。
14. 修改过程中的证据复核。
15. 各代理的职责分工。

**核心目标：建立判断与证据之间清晰、可追溯的对应关系，让模型根据实际掌握的材料形成适当强度的判断，并能够说明判断是如何得出的。**

## 2. 基本概念

### 2.1 判断（Claim）

判断是文章希望表达、解释或证明的一个具体观点。

例如：

「研发投入增加能够促进企业创新产出。」

这是一项关于研发投入与创新产出之间关系的判断。

### 2.2 证据（Evidence）

证据是用于支持、检验或修正某项判断的材料。

常见形式包括：

- 原始数据。
- 官方统计资料。
- 政策文件。
- 企业公告。
- 学术研究。
- 实验结果。
- 调查记录。
- 访谈资料。
- 经过验证的事实。
- 合理的逻辑推导。

证据需要与具体判断建立联系。

### 2.3 证据来源（Source）

证据来源是材料的原始出处。

例如：

- 国家统计局发布的统计数据。
- 企业年度报告。
- 政府发布的政策文件。
- 学术期刊中的实证研究。
- 用户提供的原始调查数据。

模型需要保留证据来源，以便后续核查。

### 2.4 论据（Supporting Argument）

论据是用于支持某项判断的事实、理论或其他理由。

论据通常需要经过一定的推理，才能支持最终结论。

例如：

前提：企业研发活动需要持续的资金投入。

证据：企业研发支出数据。

推理：融资约束缓解可能增加企业可用于研发的资金。

判断：融资约束缓解可能促进企业创新活动。

### 2.5 推理依据（Warrant）

推理依据是连接证据与判断的逻辑关系。

例如：

证据：某企业获得了更多外部技术资源。

判断：该企业的创新活动可能受到促进。

两者之间需要解释：

企业如何接触、吸收和应用外部技术资源，以及这些活动如何影响创新产出。

这个连接过程就是推理依据。

### 2.6 证据充分性（Evidence Sufficiency）

证据充分性是指现有材料是否足以支持当前判断。

例如：

一份企业公告能够证明企业参与了某项技术合作，但未必足以证明技术合作提高了企业创新能力。

### 2.7 证据有效性（Evidence Validity）

证据有效性关注材料能否合理反映所要研究的对象或关系。

例如：

专利申请数量可以反映部分创新活动，但不能完整代表企业创新质量。

### 2.8 判断强度（Claim Strength）

判断强度是指一项表达所包含的确定程度和适用范围。

例如：

- 可能存在影响。
- 与某项结果存在关联。
- 有助于改善某项结果。
- 显著提高某项结果。
- 必然导致某项结果。

不同表达需要不同程度的证据支持。

### 2.9 证据链（Evidence Chain）

证据链是由多个证据和推理环节组成的支持结构。

例如：

```text
政策文件
   |
   v
确认政策实施
   |
   v
企业参与名单
   |
   v
确认企业受到政策影响
   |
   v
企业专利数据
   |
   v
观察创新产出变化
   |
   v
因果识别与稳健性检验
   |
   v
形成政策效果判断
```

### 2.10 基本原则

- 为重要判断明确对应的证据。
- 保留证据的原始来源。
- 区分证据与解释。
- 明确证据支持判断的具体方式。
- 根据证据充分程度确定判断强度。

## 3. 判断的不同类型及其证据要求

不同类型的判断，需要不同形式的证据。

模型应当先识别当前正在表达什么类型的判断，再确定需要什么材料。

### 3.1 事实判断

事实判断描述某件事情是否发生。

例如：

「某创新园区于2018年正式揭牌。」

需要：

- 官方公告。
- 政府文件。
- 园区官方网站。
- 可靠的同期报道。

这类判断重点关注事实是否真实、时间是否准确以及来源是否可靠。

### 3.2 描述性判断

描述性判断用于说明某种现象或特征。

例如：

「近年来，企业研发投入总体呈增长趋势。」

需要：

- 连续时间序列数据。
- 统计口径说明。
- 数据来源。
- 趋势分析。

单个年份的数据通常不足以支持长期趋势判断。

### 3.3 比较性判断

比较性判断用于说明两个或多个对象之间的差异。

例如：

「处理组企业的创新产出高于控制组企业。」

需要：

- 可比的样本。
- 一致的指标口径。
- 合理的统计方法。
- 必要的差异检验。

如果进一步声称这种差异具有统计显著性，还需要相应的统计检验结果。

### 3.4 相关性判断

相关性判断说明两个变量之间存在统计关联。

例如：

「企业研发投入与专利申请量呈正相关。」

需要：

- 相应的变量数据。
- 相关性分析。
- 统计结果。
- 必要的控制条件。

相关性能够说明变量之间存在联系，但不能单独确定因果方向。

### 3.5 因果性判断

因果性判断说明某个因素对另一个因素产生了影响。

例如：

「融资约束缓解促进了企业创新。」

需要：

- 合理的研究设计。
- 明确的处理变量和结果变量。
- 合适的识别策略。
- 对潜在混杂因素的处理。
- 必要的稳健性检验。

因果判断需要说明观察到的变化为什么能够归因于目标因素。

### 3.6 机制判断

机制判断解释某种影响通过什么过程发生。

例如：

「融资约束缓解通过增加研发资金供给促进企业创新。」

需要：

- 相关理论依据。
- 作用过程的合理解释。
- 能够支持机制的经验材料。
- 必要的机制检验。

仅仅发现融资约束与创新产出存在关联，并不能自动证明资金供给机制成立。

### 3.7 评价性判断

评价性判断对某种现象作出价值或质量评价。

例如：

「某项政策取得了较好的实施效果。」

需要：

- 明确评价标准。
- 相应的评价指标。
- 实际执行情况。
- 评价对象和时间范围。

如果没有明确评价标准，模型容易将个人判断包装成客观结论。

### 3.8 预测性判断

预测性判断对未来情况作出推断。

例如：

「未来企业研发投入将继续增长。」

需要：

- 历史数据。
- 预测模型。
- 关键假设。
- 影响因素。
- 不确定性分析。

预测结果需要明确其依赖的条件。

### 3.9 推广性判断

推广性判断将已有研究结果应用于更广泛的对象。

例如：

「该政策能够促进我国企业创新。」

如果原始研究只覆盖某几个地区的上市公司，就需要进一步分析结果能否推广到其他地区、企业类型和政策环境。

### 3.10 判断类型与证据要求

| 判断类型 | 主要证据要求 |
|---|---|
| 事实判断 | 官方文件、原始记录、可靠来源 |
| 描述性判断 | 统计数据、调查资料 |
| 比较性判断 | 可比样本、统计检验 |
| 相关性判断 | 变量数据、相关性分析 |
| 因果性判断 | 因果识别设计、稳健性检验 |
| 机制判断 | 理论依据、机制证据 |
| 评价性判断 | 评价标准、评价指标 |
| 预测性判断 | 历史数据、预测模型、假设 |
| 推广性判断 | 外部有效性及适用条件 |

### 3.11 基本原则

- 先识别判断类型。
- 根据判断类型确定证据要求。
- 区分描述、解释、因果和评价。
- 让证据与判断承担相应的论证任务。
- 避免使用一种证据支持所有类型的判断。

## 4. 证据的不同形式

证据具有不同来源和表现形式。

模型需要根据研究问题选择合适的证据。

### 4.1 原始资料

原始资料直接记录某项事实或活动。

例如：

- 企业公告。
- 政策原文。
- 实验记录。
- 访谈录音。
- 原始调查问卷。
- 企业财务报表。

原始资料通常适合核查具体事实。

### 4.2 统计数据

统计数据用于描述变量分布、变化和相互关系。

例如：

- 企业研发投入。
- 专利申请数量。
- 企业营业收入。
- 地区经济指标。
- 劳动力就业数据。

使用统计数据时，需要关注数据口径、样本范围和统计方法。

### 4.3 学术文献

学术文献能够提供：

- 理论依据。
- 已有研究结论。
- 研究方法。
- 经验事实。
- 领域争议。
- 研究局限。

使用文献时，需要明确它具体支持哪项判断。

文献中出现某个观点，并不意味着该观点已经适用于当前研究对象。

### 4.4 官方文件

官方文件适合核实：

- 政策内容。
- 政策发布时间。
- 政策实施范围。
- 制度规定。
- 官方认定事项。

例如：

研究某项产业政策时，政策原文能够确认政策规定，但不能单独证明政策已经产生预期效果。

### 4.5 实验结果

实验结果可以用于检验特定条件下的现象和关系。

需要关注：

- 实验设计。
- 实验条件。
- 样本选择。
- 测量方法。
- 重复性。
- 结果适用范围。

### 4.6 访谈与观察资料

访谈和观察能够提供行为过程、主体认识和具体情境的信息。

例如：

企业负责人说明企业如何使用园区提供的技术资源。

这些材料可以帮助理解作用机制，但需要考虑受访者的认知偏差和信息完整性。

### 4.7 逻辑推导

部分判断可以通过已有前提和合理推理获得支持。

例如：

如果企业的研发预算确实增加，并且其他条件相应满足，那么企业可用于研发活动的资金可能增加。

这种支持依赖前提和推理关系。

### 4.8 案例材料

案例能够展示具体事件和作用过程。

例如：

某家企业通过园区合作获得技术支持，并形成了新的研发成果。

案例适合解释具体过程，但单个案例通常不足以证明普遍规律。

### 4.9 证据形式比较

| 证据形式 | 主要用途 | 需要关注的问题 |
|---|---|---|
| 原始资料 | 核实事实 | 来源、真实性 |
| 统计数据 | 描述和分析现象 | 口径、测量 |
| 学术文献 | 提供理论与研究依据 | 研究对象、方法 |
| 官方文件 | 确认制度和政策 | 文件效力、适用范围 |
| 实验结果 | 检验特定关系 | 实验条件、可重复性 |
| 访谈资料 | 理解行为过程 | 代表性、主观偏差 |
| 逻辑推导 | 支持推论 | 前提与推理 |
| 案例材料 | 解释具体过程 | 外部推广范围 |

### 4.10 基本原则

- 根据判断类型选择证据形式。
- 优先核查能够直接支持关键事实的原始材料。
- 根据研究问题使用不同证据来源。
- 明确案例、统计结果和理论推导各自能够支持什么。
- 记录证据的来源和适用范围。

## 5. 证据与判断的匹配

证据的存在并不意味着它能够支持文章中的任意判断。

模型需要逐项检查证据与判断之间的对应关系。

### 5.1 相关性

证据是否真正涉及当前判断？

例如：

企业营业收入增长可以说明企业经营规模扩大，但它与企业创新能力之间还需要建立具体联系。

### 5.2 直接性

证据是否直接支持当前判断？

例如：

企业公告能够证明企业签署了技术合作协议。

但如果要证明合作已经形成实际研发成果，还需要其他材料。

### 5.3 充分性

现有证据是否足以支持判断？

例如：

一家企业的创新案例能够说明某种机制可能存在，但通常不足以支持所有企业都会产生相同结果的结论。

### 5.4 可靠性

证据来源是否值得信赖？

例如：

企业正式公告与未经核实的网络评论，在事实确认方面具有不同的可靠程度。

### 5.5 有效性

证据能否合理反映目标概念？

例如：

专利申请量可以衡量部分创新活动，但如果研究关注创新质量，还需要考虑其他指标。

### 5.6 代表性

证据所覆盖的对象是否符合判断范围？

例如：

研究样本主要来自大型上市公司，结论推广到小微企业时需要考虑企业规模和资源条件的差异。

### 5.7 时效性

证据是否适用于当前讨论的时间范围？

例如：

十年前的行业数据未必能够直接描述当前市场情况。

### 5.8 独立性

多项证据是否来自相互独立的信息来源？

如果多个网站转载同一份新闻稿，它们不能简单地被视为多份独立证据。

### 5.9 可追溯性

能否找到证据的原始出处？

例如：

某篇文章引用了企业专利数量，但没有提供数据来源。

此时需要进一步查找原始数据库或官方记录。

### 5.10 匹配评价表

| 评价维度 | 核心问题 |
|---|---|
| 相关性 | 是否涉及当前判断？ |
| 直接性 | 是否直接支持判断？ |
| 充分性 | 证据数量和内容是否足够？ |
| 可靠性 | 来源是否可信？ |
| 有效性 | 是否准确反映目标概念？ |
| 代表性 | 是否适用于当前对象范围？ |
| 时效性 | 是否符合研究时间范围？ |
| 独立性 | 是否存在重复来源？ |
| 可追溯性 | 是否能够找到原始出处？ |

### 5.11 基本原则

- 从多个维度评价证据质量。
- 根据判断的具体内容检查证据。
- 区分直接证据和间接证据。
- 检查证据覆盖的对象和时间。
- 让每项证据的作用保持明确。

## 6. 判断强度的确定

这是本文件最重要的部分之一。

模型需要根据现有证据确定表达强度。

### 6.1 判断强度与证据支持程度

例如：

现有材料：

某企业的专利申请数量从10件增加到20件。

可以支持：

「该企业的专利申请数量有所增加。」

但如果没有其他材料，尚不足以直接支持：

「该企业的创新质量显著提高。」

两种判断所要求的证据不同。

### 6.2 判断表达的强度层次

| 判断表达 | 常见使用情形 |
|---|---|
| 可能存在 | 有一定依据，但尚未充分确认 |
| 提示 | 证据提供了初步支持 |
| 显示 | 材料能够直接呈现相关现象 |
| 表明 | 证据对当前判断具有较明确的支持 |
| 支持 | 证据符合某项判断，但仍需考虑其他条件 |
| 证实 | 已有较充分证据确认特定事实或命题 |
| 证明 | 需要非常充分且适合该判断类型的论证依据 |

这些表达不能机械地理解为固定的强度排序。

例如，「显示」适合描述数据直接呈现的现象，「支持」适合描述证据与理论判断之间的关系。

具体选择需要结合语境。

### 6.3 判断强度的四个维度

模型需要同时考虑：

**确定程度**

现有证据对判断提供了多大支持？

**因果程度**

当前材料能够支持相关性，还是能够支持因果解释？

**推广程度**

结论能够适用于个别案例、研究样本，还是更广泛的对象？

**时间程度**

证据能够说明短期变化，还是能够说明长期影响？

### 6.4 统计显著性与实际意义

在实证研究中，模型需要区分统计显著性和经济意义。

例如：

回归结果显示某个系数在1%的水平上显著。

这说明在相应统计模型和假设下，结果具有较强的统计证据。

但它并不自动意味着：

- 影响幅度很大。
- 经济意义显著。
- 政策效果具有广泛适用性。

模型还需要结合：

- 系数大小。
- 变量单位。
- 经济意义。
- 置信区间。
- 研究背景。

### 6.5 因果判断的强度

例如：

「政策实施后，企业创新产出增加。」

这是一项时间变化描述。

「政策促进了企业创新产出。」

这是因果判断。

两者需要不同的证据支持。

如果只有政策实施前后的数据，模型需要进一步考虑同期经济变化、企业选择和其他政策因素。

### 6.6 判断范围的控制

例如：

研究样本为某地区的上市公司。

可以表述：

「在研究样本中，政策实施与企业创新产出增长存在显著关系。」

如果研究设计能够支持因果识别，可以进一步作出相应的因果判断。

结论推广到其他企业和地区时，则需要额外考虑外部有效性。

### 6.7 判断强度调整示例

原始表达：

「飞地经济显著提高了企业创新能力。」

已知材料：

- 某地建立了飞地园区。
- 部分企业参与了园区活动。
- 企业专利申请量有所增加。

可以调整为：

「现有材料显示，部分参与园区活动的企业在相应时期出现了专利申请量增长的现象。这为进一步考察飞地经济与企业创新产出之间的关系提供了经验线索。」

这段表达明确区分了事实观察与因果判断。

### 6.8 基本原则

- 根据证据支持程度选择判断表达。
- 区分统计显著性与实际意义。
- 区分相关性判断与因果判断。
- 控制结论的推广范围。
- 让语言的确定程度与证据保持一致。

---

## 7. 证据与推理之间的关系

证据需要通过合理推理才能支持最终判断。

模型应当明确证据、前提、推理和结论之间的联系。

### 7.1 基本结构

```text
证据
  |
  v
提取事实
  |
  v
明确相关前提
  |
  v
建立推理关系
  |
  v
形成判断
  |
  v
确定结论范围
```

### 7.2 示例：专利申请量与创新产出

证据：

企业专利申请数量增加。

事实判断：

企业专利申请活动有所增加。

理论联系：

专利申请是企业创新活动的一种可观测表现。

推理：

专利申请数量增加能够反映企业专利申请活动的扩张。

结论：

企业的专利申请产出有所增加。

这里的结论与现有证据具有较直接的对应关系。

如果进一步判断创新质量提高，则需要增加专利质量方面的证据。

### 7.3 区分证据支持与理论解释

例如：

证据显示，企业研发投入与专利申请数量正相关。

理论解释可能涉及：

- 研发资金供给。
- 技术开发活动。
- 人才投入。
- 研发成果形成。

统计结果可以支持变量之间存在关系，但具体机制仍需要进一步分析。

### 7.4 区分单项证据与完整证据链

一份政策文件可以证明政策规定。

一份企业公告可以证明企业参与。

一组专利数据可以描述创新产出变化。

这些材料分别支持不同判断。

需要进一步通过研究设计将它们组织起来，才能形成更完整的政策效果论证。

### 7.5 检查推理依据

模型需要回答：

1. 证据说明了什么？
2. 证据与当前判断之间有什么关系？
3. 需要哪些前提才能建立联系？
4. 这些前提是否得到支持？
5. 是否存在其他合理解释？
6. 当前结论能够延伸到什么范围？

### 7.6 基本原则

- 让证据通过明确的推理关系支持判断。
- 区分事实描述和理论解释。
- 检查证据与结论之间的中间环节。
- 明确证据能够支持的范围。
- 避免将单项证据直接扩展成完整结论。

---

## 8. 多项证据的组织

复杂论证通常需要多项证据共同支持。

模型需要理解不同证据之间的关系。

### 8.1 互补证据

不同证据分别说明同一问题的不同方面。

例如：

- 政策文件确认政策规定。
- 企业公告确认企业参与。
- 专利数据反映创新产出。
- 访谈材料帮助理解企业行为。

这些证据共同形成更加完整的研究材料。

### 8.2 相互验证的证据

多个相互独立的来源对同一事实提供支持。

例如：

政府公告与企业公告分别确认某企业参与园区项目。

如果来源相互独立，能够提高事实核查的可信程度。

### 8.3 机制链条证据

不同证据分别支持因果机制中的不同环节。

例如：

```text
政策支持
   |
   v
企业研发资金增加
   |
   v
研发活动扩大
   |
   v
创新产出增加
```

每个环节需要相应材料支持。

### 8.4 不同证据的分工

| 证据 | 支持内容 |
|---|---|
| 政策文件 | 政策规定 |
| 企业公告 | 企业参与 |
| 财务数据 | 资金变化 |
| 研发数据 | 研发活动 |
| 专利数据 | 创新产出 |
| 访谈材料 | 具体作用过程 |

### 8.5 避免重复计算证据

多篇文章如果引用同一份原始数据或同一项研究，不能简单地视为多份独立证据。

模型需要识别证据之间的来源关系。

### 8.6 证据组织记录

```markdown
# 多项证据组织记录

## 核心判断

## 证据一
来源：
支持内容：
证据类型：

## 证据二
来源：
支持内容：
证据类型：

## 证据三
来源：
支持内容：
证据类型：

## 证据之间的关系
互补 / 相互验证 / 机制链条 / 其他

## 是否存在重复来源

## 综合支持程度

## 尚未解决的问题
```

### 8.7 基本原则

- 根据证据的实际作用进行组织。
- 区分互补证据与重复证据。
- 识别不同证据之间的来源关系。
- 让重要推理环节获得相应支持。
- 从整体上评价证据链的完整程度。

## 9. 相互冲突的证据处理

不同材料可能支持不同判断。

模型需要识别差异来源，并重新评价原有结论。

### 9.1 事实冲突

例如：

政府文件显示园区于2017年启动。

新闻报道显示园区于2018年正式运营。

这两项材料可能分别指向不同事件。

模型需要区分：

- 项目启动。
- 园区揭牌。
- 正式运营。
- 首批企业入驻。

### 9.2 数据冲突

例如：

不同数据库中的企业专利申请量存在差异。

可能涉及：

- 数据更新时间。
- 专利类型。
- 申请人匹配规则。
- 统计年度。
- 数据清洗方式。

需要核对统计口径。

### 9.3 理论冲突

例如：

不同研究对融资约束与企业创新之间的关系得出了不同结论。

模型需要比较：

- 样本范围。
- 研究时期。
- 变量定义。
- 研究方法。
- 制度环境。

### 9.4 研究结果冲突

例如：

一项研究发现政策促进企业创新，另一项研究发现政策效果不显著。

模型需要检查：

- 政策是否相同。
- 研究对象是否相同。
- 处理时点是否相同。
- 创新指标是否相同。
- 识别策略是否相同。

### 9.5 冲突处理流程

```text
发现证据冲突
      |
      v
明确冲突内容
      |
      v
核查原始来源
      |
      v
比较研究对象
      |
      v
比较时间与统计口径
      |
      v
比较研究方法
      |
      v
分析差异原因
      |
      v
重新评价原有判断
      |
      v
形成有条件的解释
```

### 9.6 冲突证据记录

```markdown
# 冲突证据记录

## 核心判断

## 证据 A
来源：
具体内容：
研究范围：

## 证据 B
来源：
具体内容：
研究范围：

## 冲突表现

## 可能原因

## 进一步核查

## 对原有判断的影响

## 最终处理结果
```

### 9.7 基本原则

- 保留存在差异的证据。
- 追溯冲突产生的具体原因。
- 区分事实差异与研究结论差异。
- 根据研究条件解释不同结果。
- 让最终判断反映现有证据的真实状态。

## 10. 证据缺口的识别与处理

模型可能已经掌握部分材料，但仍然缺少支持核心判断的必要证据。

这时需要识别缺口，并确定下一步行动。

### 10.1 事实缺口

例如：

无法确认某家企业是否正式入驻园区。

处理方式：

检索官方名单、企业公告或政府文件。

### 10.2 数据缺口

例如：

拥有企业专利申请数据，但缺少企业实际参与政策项目的时间。

处理方式：

寻找替代数据来源，或者调整研究设计。

### 10.3 理论缺口

例如：

知道企业获得外部技术资源，却无法解释资源如何影响创新产出。

处理方式：

补充理论研究，分析中间机制。

### 10.4 方法缺口

例如：

拥有政策实施前后的数据，但尚未建立合理的因果识别策略。

处理方式：

由 Logic Analyst 分析研究设计，必要时调整方法。

### 10.5 研究范围缺口

例如：

现有样本只覆盖部分企业，却希望讨论全部企业。

处理方式：

补充样本或限定结论范围。

### 10.6 用户信息缺口

例如：

模型无法确定用户希望采用哪一种指标定义。

处理方式：

向用户提出具体问题。

### 10.7 信息缺口处理表

| 缺口类型 | 主要问题 | 后续行动 |
|---|---|---|
| 事实缺口 | 事实尚未确认 | 检索原始资料 |
| 数据缺口 | 缺少必要变量 | 补充数据 |
| 理论缺口 | 缺少解释依据 | 理论检索 |
| 方法缺口 | 识别设计不充分 | 方法分析 |
| 范围缺口 | 结论超出样本 | 补充样本或限定范围 |
| 用户信息缺口 | 任务信息不足 | 询问用户 |

### 10.8 信息需求的明确表达

模型向用户询问时，应当说明：

1. 当前已经掌握什么。
2. 还缺少什么。
3. 缺失信息影响哪项判断。
4. 需要用户提供什么。

例如：

「目前已经确认园区于2018年揭牌，但尚未找到目标企业正式入驻的证据。由于入驻时间会影响处理时点的确定，你是否掌握该园区的企业名单或相关公告？」

### 10.9 基本原则

- 主动识别关键证据缺口。
- 区分可以通过检索解决的问题与需要用户提供的问题。
- 明确缺口对判断的影响。
- 为每项重要缺口确定后续行动。
- 在证据不足时保留合理的不确定性。

## 11. 证据与判断的动态调整

研究过程中，新证据可能改变原有认识。

模型需要根据新材料重新评价相关判断。

### 11.1 新证据支持原有判断

如果新材料进一步支持原有判断，可以提高其证据支持程度。

### 11.2 新证据限制原有判断

例如：

原有判断认为政策对所有企业都有促进作用。

新证据显示政策效果主要集中在技术基础较好的企业。

此时需要调整结论范围。

### 11.3 新证据改变原有机制

例如：

原有研究认为政策主要通过资金支持影响企业创新。

进一步资料显示，技术交流可能是更重要的作用渠道。

此时需要重新评价原有机制。

### 11.4 新证据推翻原有判断

如果新材料与原有结论存在直接冲突，需要重新检查前提、证据和推理过程。

### 11.5 动态调整流程

```text
获得新证据
    |
    v
核查证据来源
    |
    v
确定支持的判断
    |
    v
比较原有认识
    |
    v
判断影响方向
    |
    +----------------+
    |        |       |
    v        v       v
  加强     限定    推翻
    |        |       |
    v        v       v
调整支持程度  调整范围  重建论证
    |        |       |
    +--------+-------+
             |
             v
        更新共享知识库
             |
             v
        更新写作任务
```

### 11.6 基本原则

- 根据新证据更新原有判断。
- 保留重要认识变化的原因。
- 检查新证据对其他判断的影响。
- 及时更新共享知识库。
- 让正文与最新证据保持一致。

## 12. 写作前的证据准备

证据准备需要安排在正式写作之前。

模型应当先明确准备表达哪些判断，再确定这些判断需要什么证据。

### 12.1 第一步：提取核心判断

明确文章需要建立的主要观点。

### 12.2 第二步：拆解判断

将核心判断拆解为若干具体判断。

例如：

「飞地经济促进企业创新。」

可以拆解为：

- 飞地园区确实建立并运营。
- 企业确实参与相关园区活动。
- 企业创新产出发生变化。
- 园区活动可能通过特定机制影响创新。

### 12.3 第三步：识别判断类型

确定每项判断属于事实、描述、相关性、因果性还是机制判断。

### 12.4 第四步：确定证据要求

为每项判断明确所需资料。

### 12.5 第五步：收集证据

由 Researcher 检索公开资料，由用户提供必要的原始数据和个人材料。

### 12.6 第六步：评价证据

检查来源、相关性、可靠性、充分性和适用范围。

### 12.7 第七步：建立对应关系

将每项证据分配给需要支持的具体判断。

### 12.8 第八步：识别证据缺口

明确哪些判断已经得到支持，哪些仍然需要补充材料。

### 12.9 第九步：调整判断强度

根据现有证据调整表达方式和结论范围。

### 12.10 第十步：形成写作任务

将判断、证据和推理关系交给 Writer。

```text
      |

      |
      v

      |
      v

      |
      v

      |
      v

      |

```

## 13. 写作过程中的证据检查

正式写作过程中，模型需要持续检查新生成的判断是否具有相应依据。

### 13.1 检查新增事实

当 Writer 引入新的事实时，需要确认：

- 事实来源是什么？
- 是否已经得到核实？
- 是否符合当前研究范围？

### 13.2 检查新增结论

当 Writer 得出新的判断时，需要检查：

- 当前证据支持什么？
- 需要哪些隐含前提？
- 推理过程是否完整？
- 判断强度是否适当？

### 13.3 检查引用

当文章引用文献时，需要确认：

- 文献是否真实存在？
- 引用内容是否准确？
- 文献研究对象是否匹配？
- 文献是否真正支持当前句子的判断？

### 13.4 检查数据解释

当文章描述统计结果时，需要检查：

- 数据对应哪个变量？
- 统计口径是否明确？
- 结果的变化方向是什么？
- 是否具有统计显著性？
- 是否具有实际经济意义？

### 13.5 检查跨段落证据

一项判断可能依赖前文已经提供的材料。

Writer 需要结合全文检查证据是否已经得到说明，避免重复介绍，也避免引用尚未建立的结论。

### 13.6 Writer 反馈机制

当 Writer 发现证据不足时，可以提交：

```markdown
# 证据问题反馈

## 当前写作位置

## 当前判断

## 判断类型

## 已有证据

## 证据来源

## 当前缺口

## 对判断的影响

## 建议补充的资料

## 建议调整的表达

## 是否影响整体论证
```

### 13.7 基本原则

- 为新增的重要判断检查证据。
- 保持引用内容与原始材料一致。
- 根据统计结果准确解释数据。
- 检查跨段落的证据依赖。
- 及时反馈无法获得充分支持的判断。

## 14. 修改过程中的证据复核

文章修改可能改变判断的含义和强度，因此需要重新检查证据。

### 14.1 判断强化检查

例如：

原文：

「研究结果显示，政策与企业创新产出存在显著关联。」

修改后：

「研究结果证明，政策显著促进了企业创新。」

修改后的判断从相关性提升为因果性，需要重新检查识别设计是否支持这种变化。

### 14.2 判断范围检查

例如：

原文讨论研究样本中的企业。

修改后将结论扩展到所有企业。

需要重新检查证据是否支持更广泛的推广范围。

### 14.3 新增证据检查

如果修改时增加了新的数据或文献，需要重新核实来源和支持内容。

### 14.4 删除内容后的证据检查

如果删除了某段理论解释或事实依据，需要检查后文是否仍然能够得到支持。

### 14.5 证据依赖检查

```text
修改某项判断
      |
      v
检查原有证据
      |
      v
检查判断强度
      |
      v
检查适用范围
      |
      v
检查相关推理
      |
      v
检查其他依赖该判断的内容
      |
      v
更新证据对应关系
```

### 14.6 修改记录

```markdown
# 证据复核记录

## 修改位置

## 原有判断

## 修改后的判断

## 判断变化

## 原有证据

## 是否需要新增证据

## 判断强度是否匹配

## 适用范围是否合理

## 受到影响的其他段落

## 最终处理结果
```

### 14.7 基本原则

- 对判断强度的变化重新检查证据。
- 对适用范围的扩大重新评价证据。
- 检查删除内容对后续论证的影响。
- 保持引用内容与原始资料一致。
- 让最终版本中的每项重要判断都具有明确依据。

## 15. 判断与证据的质量评价

Evaluator 需要从以下方面评价文章。

| 评价维度 | 核心问题 |
|---|---|
| 判断明确性 | 当前判断是否具体？ |
| 判断类型 | 是否准确识别判断性质？ |
| 证据相关性 | 证据是否涉及当前判断？ |
| 证据可靠性 | 来源是否可信？ |
| 证据充分性 | 是否具有足够支持？ |
| 推理合理性 | 证据如何支持判断？ |
| 判断强度 | 表达是否超过证据支持程度？ |
| 范围一致性 | 结论是否超出证据范围？ |
| 来源可追溯性 | 能否找到原始材料？ |
| 引用准确性 | 引用是否忠实于原文？ |

### 16.1 评价结果

**通过**

重要判断具有明确依据，证据与判断匹配，结论强度合理。

**部分通过**

主要判断已经获得支持，但部分内容需要补充资料或进一步解释。

**需要补充**

存在重要证据缺口，当前材料不足以支持相关判断。

**需要调整**

判断强度、适用范围或推理关系需要修改。

**需要重新分析**

核心结论缺少必要证据，或者现有证据与原有判断存在明显冲突。

### 16.2 评价报告

```markdown
# 判断与证据评价报告

## 一、核心判断

## 二、重要判断清单

## 三、证据对应情况

## 四、证据质量评价

## 五、推理关系检查

## 六、判断强度检查

## 七、适用范围检查

## 八、引用准确性检查

## 九、尚未解决的问题

## 十、最终评价
通过 / 部分通过 / 需要补充 / 需要调整 / 需要重新分析
```

## 17. 最终原则

判断与证据的对应关系遵循以下原则：

1. 明确文章希望建立的判断。
2. 识别不同判断的性质。
3. 根据判断类型确定证据要求。
4. 区分事实、数据、理论和逻辑推导。
5. 为重要判断建立明确的证据对应关系。
6. 保留证据的原始来源。
7. 检查证据的相关性。
8. 检查证据的可靠性。
9. 检查证据的有效性。
10. 检查证据的充分性。
11. 检查证据的适用范围。
12. 区分直接证据和间接证据。
13. 明确证据与推理之间的关系。
14. 识别不同证据之间的互补和重复关系。
15. 处理相互冲突的证据。
16. 根据证据支持程度确定判断强度。
17. 区分统计显著性与实际意义。
18. 区分相关性与因果性判断。
19. 控制结论的推广范围。
20. 对尚未解决的证据缺口明确记录。
21. 根据新证据调整原有判断。
22. 对修改后的判断重新检查证据。
23. 由 Logic Analyst 负责判断与推理关系分析。
24. 由 Researcher 负责证据检索和核查。
25. 由 Writer 负责将证据与判断落实到文本。
26. 由 Evaluator 负责检查最终文本的证据支持程度。
27. 由 Prompt Architect 协调整体写作任务和信息需求。

**最终目标：让模型在写作时始终清楚自己掌握了什么证据、这些证据支持什么判断，以及判断能够达到什么程度。文章中的每项重要结论，都应当能够追溯到相应的事实、资料和推理过程。**
